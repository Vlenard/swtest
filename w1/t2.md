function calculateParkingFee(minutes, isWeekend, isVip) {
    if (minutes < 15) {
        return 0;
    }

    let hours = Math.floor(minutes / 60);
    let fee = hours * 600;

    if (isWeekend) {
        fee = fee * 0.5;
    }

    if (isVip) {
        fee = fee - 20;
    }

    if (fee > 5000) {
        fee = 5000;
    }

    return fee;
}

A kód 15 percnél rövidebb parkolásnál ingyenes parkolást ad, de pontosan 15 percnél már fizetni kell. Ezt a határértéket külön ellenőrizni kell.

A díj számítása csak a teljes órákat veszi figyelembe a Math.floor használata miatt. Például 61 perc ugyanannyiba kerül, mint 60 perc, ami lehet hibás, ha minden megkezdett órát ki kell fizetni.

A 15 és 59 perc közötti parkolásnál a hours értéke 0, ezért a függvény 0 díjat ad vissza, pedig a 15 perces ingyenességi határ után valószínűleg már kellene fizetni.

A hétvégi kedvezmény 50%, a VIP kedvezmény viszont fix 20 pénzegység. Nem derül ki, hogy ez a követelmény szerint helyes-e, ezért pontosítani kell.

VIP esetben a díj akár negatív is lehet, például rövid parkolásnál vagy alacsony díjnál. A díjat legalább nullára kellene korlátozni.

A maximum 5000-es díj felső korlátja működik, de azt is tesztelni kell, hogy pontosan 5000-nél és 5000 fölött mi történik.

Nincs ellenőrzés negatív, nulla vagy nem szám típusú minutes értékre. Negatív értéknél a függvény jelenleg hibás logika szerint működhet.

Fontos tesztesetek: 0, 14, 15, 59, 60, 61 perc, hétköznap és hétvégén, VIP és nem VIP esetben, valamint olyan hosszú parkolás, amelynél a díj eléri az 5000-et.
