function calculateTicketPrice(age, isStudent, is3D) {
    let price = 3000;

    if (age <= 6) {
        price = 0;
    } else if (age < 18) {
        price = price * 0.7;
    } else if (age > 65) {
        price = price * 0.6;
    }

    if (isStudent) {
        price = price * 0.8;
    }

    if (is3D) {
        price = price * 1.8;
    }

    return price;
}

A 6 éves korhatár hibásan van kezelve, mert az age <= 6 feltétel miatt a pontosan 6 éves személy ingyen mehet. A szabály szerint 6 éves kor alatt ingyenes, ezért itt age < 6 kellene.

A 65 éves korhatár szintén hibás, mert az age > 65 csak 66 éves kortól ad 40% kedvezményt. A szabály szerint 65 éves kortól jár a kedvezmény, ezért age >= 65 lenne helyes.

A diák kedvezményt az életkor szerinti kedvezmény után újra alkalmazza a program. Ez sérti azt a szabályt, hogy egyszerre csak a legnagyobb kedvezmény használható.

Például egy 16 éves diák jelenleg először 30%, majd további 20% kedvezményt kap, pedig csak a 30%-os kedvezmény járna.

A 3D felár számítása hibás, mert a program a teljes kedvezményes árat megszorozza 1.8-cal. Így a 3D felárra is kedvezmény vagy extra szorzás kerül.

A helyes megoldásnál először ki kell számolni a legnagyobb kedvezményt az alapárból, majd ehhez hozzáadni a 800 Ft 3D felárat.

Nincs ellenőrzés negatív életkor és 120 év feletti életkor esetén. Ilyen adatnál hibát kell jelezni, vagy külön érvénytelen eredményt kell visszaadni.

A szabályok miatt fontos tesztesetek: -1, 0, 5, 6, 17, 18, 64, 65, 120 és 121 éves kor, valamint diák és nem diák, illetve 2D és 3D film esetén.

A legfontosabb hibák tehát a hibás korhatárok, a kedvezmények összeadása vagy egymás utáni alkalmazása, a 3D felár rossz számítása és az érvénytelen életkorok hiányzó kezelése.
